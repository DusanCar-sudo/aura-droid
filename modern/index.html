02 — Two ways to run it

Pair it with a project, or go it alone.

Aura Droid is the client. The agent itself is Aura Code. Put it beside your project on a PC, or skip the computer and talk to a model straight from the phone.

Paired

Aura Code on your PC, steered from your phone.

Aura Droidthe phone
pinned TLS
Aura CodePC or Termux
  • Your real project. The agent works on your files with the desktop's tools; the phone is the control surface.
  • Wi-Fi or USB. Pair with a 6-character code. Over Wi-Fi the phone pins the desktop's identity; if it changes without you re-pairing, something else is answering.
  • Termux works too. Run aura serve on the phone and pair to 127.0.0.1. Whatever permissions you give that environment, sudo or root included if you choose, are the ceiling for what she can do there.
# USB, from the computer
adb reverse tcp:7337 tcp:7337
aura serve
aura devices add "my phone"

Wi-Fi uses aura serve --lan. Step-by-step: pairing guide (PDF)

No computer. Just you, a key, a model.

03 — Control

Aura asks first. You decide when she doesn't.

An agent on your phone should have exactly as much rope as you hand it. By default, every action needs your approval. Loosen it as far as you like, one chat at a time or everywhere.

  1. Ask every timeThe default. Each tool call waits for Allow or Deny.
  2. Allow for this chatChoose “Allow all” on a prompt and tools run for the rest of that conversation.
  3. Approve all actions 0.4.0A setting that changes the default in every conversation.
  4. Sandbox out 0.4.0Lets Aura reach past the app sandbox when you ask. Sensitive app data stays off-limits.
Settings try it

Approve all actions

Let Aura run every tool without asking. Off means it asks before each action, as usual.

Sandbox out

Let Aura reach beyond the app sandbox on request: read and write files elsewhere on the phone, and move anywhere the device user can.

07 — Questions

Before you install.

Do I need a computer?

No. Turn on “Run without a desktop,” give the app a base URL, a model ID and an API key, and Aura runs on the phone with her own tools and memory. To work on your real repository, pair a desktop running Aura Code, or run Aura Code in Termux.

Which models does it use?

When paired, whichever model your Aura Code instance is set up with: Claude, GPT, Gemini, DeepSeek, Ollama and others. On the phone alone, any OpenAI-compatible endpoint you point it at.

What can Aura do on my phone?

By default she stays in her own workspace folder and asks before every action. “Allow all” relaxes that for one chat. In 0.4.0, Sandbox out lets her reach elsewhere on request, and sensitive app data stays off-limits regardless.

Where do my API key and chats live?

API keys are held in the Android Keystore, and chat history is stored locally in the app. Requests go to the model endpoint or the desktop you configure, plus any page you ask Aura to fetch. Over Wi-Fi the phone pins the desktop's identity, so it can tell if something else starts answering.

How does it relate to Aura Code?

Aura Code is the agent, a model-agnostic autonomous coding tool for the command line. Aura Droid is its Android client. Agent behaviour lives in aura-code; this app is the phone-sized surface for it.

Is it open source?

Yes, Apache-2.0. Read it, build it, fork it on GitHub.
